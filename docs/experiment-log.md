# Experiment Log

This file records the experiments carried out for the Public Transport Demand and Occupancy Prediction project. Each experiment will be added after it has been run, along with its results and observations.

For each experiment, the following details will be recorded:

- **Goal:** What the experiment is intended to find out.
- **Data:** Dataset version, selected time period and any relevant filtering.
- **Method:** Baseline or prediction model being tested, including important settings.
- **Data split:** Training, validation and test periods used in the experiment.
- **Metrics:** Measures used to evaluate the predictions.
- **Results:** Values obtained from the actual experiment run.
- **Notes:** Observations, unexpected results or issues that need further investigation.
- **Reproduction:** Commands and settings required to run the experiment again.
