# Project Plan

## What I'm working on

The aim is to predict public transport demand and occupancy using data and machine learning. The first step is to understand the dataset and decide how to approach the prediction problem.

## Work to be done

### 1. Understand the data
- Check what information is available and how it is organised.
- Look for missing values, duplicate records and unusual entries.
- Decide which fields will be useful for prediction.

### 2. Build the prediction model
- Start with a simple baseline to get a reference result.
- Try a suitable forecasting model and compare its performance with the baseline.
- Check that the model only uses information available at prediction time.

### 3. Check the results
- Keep training and testing data separate by time.
- Calculate suitable error metrics.
- Look at where predictions perform well and where they fail.

### 4. Occupancy prediction
- Work out how occupancy can be estimated from the available data.
- Record the assumptions being made and the situations where the estimates may be unreliable.

### 5. Keep the work reproducible
- Document the setup and commands needed to run the project.
- Save experiment results and note any changes made.
- Make sure the reported results can be checked again.

## Current status

The project plan is in place. The implementation and experiments will be documented as the work progresses.

## Next step

Inspect the dataset, understand its columns, and establish a simple baseline before moving to more complex models.
