# Experiment Log

I'll use this file to keep track of the experiments and results as the project develops.

For each experiment, I'll record:

- **Goal:** What I'm trying to find out.
- **Data:** Which dataset and time period are being used.
- **Method:** The baseline or model being tested.
- **Metrics:** How the predictions are being evaluated.
- **Results:** The values obtained from the actual run.
- **Notes:** Anything interesting, unexpected or worth investigating.
- **How to reproduce:** The commands and settings needed to run it again.
